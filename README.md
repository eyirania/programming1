# StudyOS — Programming I

영재학교 프로그래밍Ⅰ 전용 정적 시험 대비 앱. 제공된 **PDF 11개·145페이지**와 추가 선생님 코드 **1_숙직.cpp**를 근거로 만들었습니다.

## 바로 사용하기

미리보기에서 Overview → Concepts → Memorization → Practice → Exam 순으로 학습할 수 있습니다. 기록은 해당 브라우저의 IndexedDB에 저장됩니다. **Progress → JSON 백업**으로 다른 기기로 옮길 수 있습니다.

- 개념 66개, 플래시카드 156장, 창작 예상 문제 150문항
- 분석·심화(Level 4~5) 67문항, 20문항 모의고사 3회
- 60개 실행 검증 코드, 연결 코드 패턴 20개
- 각 모의고사는 11개 자료를 포함하며 난이도별 2/3/6/6/3문항, 회차 간 중복 없음
- 원본 PDF 페이지, 선생님 코드 행 번호, 정정·보충 사항 연결

## 코드 스타일

수업에 맞춰 **stdio.h, scanf/printf, 일반 배열과 첨자 반복문**을 기본으로 합니다. 60개 코드 중 40개는 C, 20개는 C 입출력에 수업의 C++ STL만 사용합니다. `algorithm`은 sort·경계 탐색·min, `queue/stack/vector`는 해당 자료구조 문제에만 포함합니다. `iostream`, `cout`, `auto`, 람다, 범위 기반 for, std::string은 사용하지 않습니다.

선생님 원본은 Sources에서 확인할 수 있습니다. 세 개의 독립된 main을 포함한 자료이므로 풀이별로 분리한 파일도 제공합니다. 원본은 바꾸지 않았습니다.

## 주요 기능

- **Overview**: 복습 예정 카드, 완료 개념, 미해결 문제, 오답 기반 추천
- **Curriculum / Concepts**: 원본 단원 순서, 핵심·오개념·코드 패턴, 학습 완료 표시
- **Memorization**: 답안 공개 후 Again / Hard / Good / Easy, 예정일 자동 관리, 무작위·취약 항목 우선, 단계별 힌트와 능동 회상
- **Practice**: 검색·단원·유형·난이도 필터, 출력 자동 채점, 서술형 기준별 자기 채점
- **Exam**: 전체·탐색·관계·단원·취약·고난도 범위, 문제 수·시간 지정, 미응답 표시, 새로고침 복구, 시간 만료 자동 제출
- **Mistakes / Progress**: 원인 분류, 다시 풀기, 복습 상태, 수준·유형·단원별 결과, 카드별 마지막 학습일·다음 일정·성공률
- **Sources**: 원본 11개 PDF, 추가 선생님 코드, 정정·보충 12건

`⌘K` / `Ctrl+K`는 통합 검색입니다. 검색 후 Enter로 첫 결과를 열고 Tab으로 선택합니다. 카드에서는 입력창·버튼에 포커스가 없을 때 Space로 공개, 1~4로 기억 정도를 평가합니다.

## 실행·빌드

Node.js 22.12 이상인 22 LTS, 24 LTS 또는 26 이상을 사용합니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`dist/`가 정적 배포 결과입니다. 파일 더블클릭 대신 정적 웹 서버나 GitHub Pages로 여세요. 런타임에는 서버 처리, 로그인, AI API, 외부 폰트 CDN이 없습니다. 페이지와 글꼴, PDF는 같은 정적 사이트에서 제공됩니다. 오프라인 재접속을 보장하는 서비스 워커는 포함하지 않습니다.

## GitHub Pages

1. 이 폴더의 내용을 GitHub 저장소 루트에 올립니다.
2. 저장소 Settings → Pages → Source에서 **GitHub Actions**를 선택합니다.
3. main 브랜치에 반영하거나 **Deploy StudyOS to GitHub Pages** 워크플로를 실행합니다.

워크플로가 설치 → 테스트 → 빌드 → Pages 배포를 실행합니다. 상대 자산 경로(`base: './'`)와 해시 라우팅을 사용하므로 `https://사용자.github.io/저장소/#/concepts` 형태의 하위 경로에서 새로고침할 수 있습니다. 저장소가 아직 연결되지 않아 실제 원격 배포는 실행하지 않았습니다.

## 콘텐츠와 검증

데이터는 `src/content/` JSON에 분리되어 있습니다. 새 문제에는 고유 ID, 원본 근거, 조건, 정답, 해설, 채점 방법, 검증 상태를 포함하세요. `verification.status`가 `passed`인 문제만 출제됩니다.

```sh
# Python 3 + clang/clang++ 필요
npm run verify:content
npm run verify:teacher
```

첫 명령은 C11/C++11로 코드를 컴파일하고 경고를 오류로 취급하며, UB sanitizer 실행 결과를 독립 참조 출력과 비교합니다. 모든 검사가 성공한 뒤에만 검증 상태와 해시를 기록합니다. 두 번째 명령은 선생님의 세 풀이를 따로 검증합니다. 검증은 개발 단계에서 수행하며 브라우저에서 코드를 실행하지 않습니다.

## 채점과 기록의 의미

서술형 60문항은 의미를 자동 판정하지 않습니다. 수학적으로 동치인 답을 인정하도록 모범 답안과 기준별 자기 채점을 제공합니다. 채점 전 점수는 잠정치이고, 미채점 답안은 유형별 정답률의 분모에서 제외됩니다. 미응답은 0점입니다. 학생의 자기 평가가 정확해야 점수와 추천도 정확합니다.

간격 반복은 단순한 규칙 기반 스케줄러이며 Anki/FSRS와 동일한 구현이라고 주장하지 않습니다. 브라우저 데이터를 삭제하면 기록도 사라지므로 정기적으로 JSON을 백업하세요. 다른 탭·기기 간 동시 편집 동기화는 제공하지 않습니다. 원본 자료와 창작 문항의 저작권은 각각의 권리자에게 있으며, 실제 학교 시험지를 재현한 자료가 아닙니다.
