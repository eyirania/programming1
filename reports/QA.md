검증일: 2026-10-13. 최종본은 C 입출력 중심으로 수정된 버전이다.

타일의 보드 열거, 정수 분할 수열 열거, 이진 암호/복원 278개 왕복, 노드 거리 1,521쌍, 절반 합 1..1,000을 독립 검증했다. 숫자 뒤집기·정수 나눗셈·탐욕적 점프·정방향 DP 갱신·큐 중복 삽입의 반례도 실제로 재현했다. 검증 결과는 `content-validation.json`과 `teacher-code-validation.json`에 남겼다.

학문적 문항 검토와 실행 검증을 구별한다. 실행 검증이 모든 가능한 입력의 정당성 증명을 대신하지 않으며, 학교 교사의 별도 감수를 받은 것으로 표시하지 않는다.

## 자동 테스트 및 빌드

- Vitest **26개 테스트 통과**, 세 테스트 파일 모두 통과.
- TypeScript 검사 및 production build 성공. 번들 크기 경고 없이 분리 빌드.
- 복습 간격·기억 성공/실패·숙달 조건, 토큰 채점과 미응답, 서술형 보류 처리 검증.
- 시간 만료 경계, 만료 후 수정 차단, 중복 제출 방지, 잘못된 시험 인덱스 차단 검증.
- IndexedDB 저장 후 복구, 복원 전 자료 검증, 원자적 복원 및 잘못된 참조·버전·제출 기록 거절 검증.
- 모든 개념·카드·문제의 출처 페이지, ID 연결, 문항 검증 해시, 모의고사 중복과 수준 분포 검증.
- C 입출력 스타일과 허용 헤더 검사, 선생님 원본 해시와 행 번호 검사.
- 설치 의존성 검사의 알려진 취약점은 수정 버전 적용 후 **0건**. 개발 도구 Vitest와 수식 렌더러 KaTeX를 갱신했다.

## 실제 브라우저 검증

Codex 내장 Chromium 브라우저에서 직접 조작했다. 데스크톱 1440×1000, 모바일 390×844 크기를 확인했다. 전체 버튼 조합·모든 브라우저를 자동으로 전수 검증한 것은 아니며 다음 대표 흐름을 확인했다.

1. 객관식 정답 제출 → 정답·해설 표시. 오답 제출 → 오답 노트 생성.
2. 오답 원인 선택, 새로고침, 기록 확인.
3. 플래시카드 시작 → 답 숨김 → 답 공개 → Good → 다음 카드 및 다음 복습일 기록.
4. 개념 완료 표시 → 능동 회상 → 힌트 단계 공개 → 설명 확인.
5. 모의고사 시작 → 정답·해설 및 일반 탐색 메뉴 숨김 → 문항 이동 → 답안 입력 → 새로고침 후 응답·위치·남은 시간 유지.
6. 시험 종료 → 미응답 수 확인 → 잠정 점수 → 서술형 기준 세 개 자기 채점 → 최종 점수 5점에서 10점으로 갱신.
7. 실제 1분 제한 시험이 만료되자 자동으로 제출되어 결과 화면으로 이동.
8. JSON 백업 다운로드 → 같은 파일 선택 → 내용 검증·복원 → 새로고침 후 풀이 23건/복습 카드 1장/시험 2회 유지.
9. 통합 검색의 문제 검색 → Enter로 이동. 모바일 메뉴 열기·화면 이동.
10. 수정한 숙직 코드의 stdio.h/algorithm/printf 표시 → 출력 2 입력 → 정답 판정. 선생님 원본 #3 코드 펼치기 및 행 번호 확인.
11. production 빌드를 `/studyos/` 하위 경로에서 실행하고 해시 라우트 새로고침, 상대 PDF·코드 링크, 글꼴·스타일 표시 확인.
12. 모바일 Overview·Practice·Sources에서 문서 가로 넘침 없음. 긴 코드는 코드 블록 안에서 가로 스크롤.
13. 최종 정적 배포본 콘솔에 확인된 오류·경고 없음.

## 발견 후 수정한 사항

- 수업과 달랐던 공통 C++ 헤더·cout·고급 문법을 C 입출력, 일반 배열, 첨자 반복으로 교체했다.
- 호출 횟수 출력에서 함수 호출과 카운터 읽기의 평가 순서가 섞이지 않도록 반환값을 먼저 저장했다.
- 예측 정답 개수를 암시하던 격자 문제 제목을 중립적인 제목으로 바꿨다.
- 모의고사의 특정 범위·난이도 쏠림을 줄이고 회차마다 전체 난이도와 11개 자료를 포함했다.
- 결과 화면의 상태 선택자가 매번 새 배열을 반환하던 부분을 고쳐 불필요한 갱신을 막았다.
- 미응답 서술형은 0점으로 유지하고 빈 답안에 자기 채점 점수를 부여하지 못하게 했다.
- 원본 번호와 다른 고급 분류를 혼동하지 않도록 PDF 페이지와 코드 행 번호를 별도 표시했다.

## 배포·사용 한계

- GitHub 저장소가 연결되지 않아 **원격 GitHub Pages 배포는 미실행**이다. 워크플로와 최종 dist를 제공한다.
- Chromium에서 검증했으며 Safari/Firefox/iOS 실기기 검증은 수행하지 않았다.
- 브라우저 내 코드 실행 및 AI 의미 채점 기능은 제공하지 않는다. 서술형 점수는 학생의 기준별 자기 평가이다.
- 기록은 브라우저별 로컬 저장이며 다중 탭 동시 편집·기기 간 자동 동기화는 지원하지 않는다.
- 자동 반복 스케줄은 단순 규칙 기반이며 Anki/FSRS를 완전히 재현하지 않는다.
- 교재 원본, 실제 학교 시험지는 제공되지 않았다. 수업 자료 기반의 창작 예상 문제임을 표시한다.
