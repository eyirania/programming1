## 2단계 — 실제 수업 범위

탐색 기반은 원본의 02 선형 구조 → 03 비선형(1) → (2) → (3) 순서를 유지한다. 선택·퀵 정렬, 순차·이분 탐색, 경계 탐색, 그래프·트리, 행렬·목록, vector/pair, 재귀/스택 DFS, 큐 BFS, 두더지 굴을 포함한다. 참고자료의 주소·스택/큐·미로 그래프화·입력 순서 탐색은 별도 보충 근거로 연결한다.

## 발견한 오류·보충 사항

- **lower_bound / upper_bound 뒤바뀜** (프로그래밍Ⅰ - 참고자료(sasapro.enn.kr).pdf, PDF p.2): 첫 문장의 두 함수 설명이 뒤바뀜. → 선형 슬라이드 p.7 및 C++ 표준 초안에 따라 lower >=, upper >로 정정. 표의 설명은 이미 올바름.
- **주소 출력 형식** (프로그래밍Ⅰ - 참고자료(sasapro.enn.kr).pdf, PDF p.1): 포인터를 %d로 출력하며 특정 주소값을 예시로 제시. → %p와 (void*)로 출력. 수치 주소 자체는 고정 정답으로 사용하지 않음.
- **경계 탐색 코드의 초기값** (프로그래밍Ⅰ - [02] 선형 구조의 탐색.pdf, PDF p.7): result의 선언과 실패 시 초기값이 생략된 학습용 코드. → 앱의 완성 패턴은 result=n으로 초기화. 원본 코드는 암기용 부분 코드로 취급.
- **시간 측정 자료형·범위** (chap1.pdf, PDF p.6): clock() 결과를 time_t에 저장. int 최대 입력에서 i++도 넘칠 수 있음. → 실행 예시는 clock_t 사용 및 64비트 반복 변수. clock은 CPU 시간으로 벽시계 시간과 구별.
- **의도적으로 제시된 숫자 뒤집기 오류** (chap2.pdf, PDF p.5): 내부 수의 선행 0이 사라지는 전략 #3. → 1010에서 101 대신 11. 자리 폭 상태 또는 반복 누적으로 수정. 오류 찾기 과제로 보존.
- **타일 입력 조건 충돌** (chap3.pdf, PDF p.12): 문제 p.8의 m<=40000과 비교 실습 m=99999가 다름. → 기본 문제 범위와 별도 성능 비교 실습을 구분. 앱 문제마다 m 명시.
- **파일명과 표제 번호** (chap4.pdf, PDF p.1): chap4.pdf 표제는 Chap #5. chap6.pdf는 Chap #9. → 파일명과 원본 표제를 각각 보존하고 임의로 번호를 맞추지 않음.
- **완전이진트리 정의** (chap4.pdf, PDF p.3): 마지막 층 이외 노드는 자식 둘이라는 설명은 표준 complete 정의보다 강함. → 표준은 마지막 층 이전은 가득 차고 마지막 층은 왼쪽부터 채움. 거리 문제는 부모 x/2 번호 규칙에 의존.
- **색별 반환 패턴의 빠진 기초 경우** (chap4.pdf, PDF p.8): 다른 색 단일 칸에서 0 반환이 생략됨. → 단색이면 원하는 색인지에 따라 1/0 반환 후 종료. n=0 분할 방지.
- **정수 분할 전개식 오타** (chap5.pdf, PDF p.3): f(n-2,2) 항이 연속으로 두 번 등장. → 합은 Σ(i=1..min(n,k)) P(n-i,i). 두 갈래 식과 일치하도록 정정. p.6에도 같은 오타.
- **상향식 예시의 진행 방향** (chap5.pdf, PDF p.11): k+f(k+1) 재귀 예시를 상향식으로 제시. → 원본 분류는 보존하되 호출 순서와 실제 반환·계산 순서를 별도 설명.
- **깊이·높이 영문 표기** (프로그래밍Ⅰ - [03] 비선형 구조의 탐색(1).pdf, PDF p.6): 깊이=Level, 높이=Depth로 표기. → 일반 용어 depth=루트부터 거리, height=하위 최장 거리. 시험에서는 간선 수 기준을 명시.

정정된 경계 함수 의미는 [C++ 표준 초안](https://eel.is/c++draft/alg.binary.search)과 대조했다. GitHub Pages 설정은 [Vite 정적 배포 안내](https://vite.dev/guide/static-deploy.html#github-pages)에 맞춰 상대 자산 경로와 해시 라우팅을 사용한다.
